# 篩は言葉を振るう — エラトステネスから furui へ

`bonsai/furui` は「意味でフォルダを振るう」整理の槍。名前の由来は紀元前3世紀、エラトステネスの篩（ふるい）だ。

## 1. 素数は数えながら見つからない

エラトステネスの篩は、素数を「発見する」方法ではない。「合成数（素数でないもの）を先に振るい落とす」方法だ。2 を残し 2 の倍数を消す。3 を残し 3 の倍数を消す。掛け算表すら持たず、**消すことだけで**残ったものが素数である。

この方法が2000年以上残った理由は、計算が乱暴なのに結果が正確なところだ。素数という「個別の性質」を直接判定しているのではなく、「何かで割れる」という**公約的な性質**で一括して消している。判定は後回し、篩いが先。

## 2. ファイルは素数じゃない

整理の現場で、あらゆるファイルの正体を個別に「判定する」ことはできる。だがそれは我々がやろうとしていることの誤解だ。`.md` だからドキュメント、`.py` だからコード、という名前の検査は合成数判定に近い — フォルダ構造や命名が崩れているところでは、あてにならない。

furui の思想は篩と同じだ。**正体を証明せず、間違いを振るう**。

- エージェントの定義ファイルがプロジェクト置き場に混ざっていれば → 篩う
- 一時ファイル・ログ・`.bak` が知識の wiki に沈んでいれば → 篩う
- 何十年も放置された solid 相のリポジトリが熱い現場の隣に並んでいれば → 篩う

## 3. 命題で振るう

しかし furui はエラトステネスと決定的に違う。彼の篩は「2 で割れる」という**数値的事実**で振るった。ファイルにそんな事実はない。代わりに furui は **Jev という命題判定器**を使う。

昔の私なら正規表現で `agent|skill|project|wiki` を探しただろう。それは素因数分解で素数を探すのと似ている — 字面に依存し、語が文章の奥に隠れると見えない。

Jev は行と命題を一緒に読むクロスエンコーダだ。`agents/kiyoshi.md` というパスと「これは AI エージェントの人柄定義か」という質問を突き合わせ、確率を返す。パスに "agent" と書いてあっても実体が議事録なら wiki に振るい落とされる。**名前の一致ではなく、事実性の一致**で落とす。これがエラトステネスの篩が数に対してやったことの、言葉に対する翻訳だ。

## 4. 確率の篩目

エラトステネスの篩は篩目が厳密だった。「2 で割れるなら落とす」に曖昧さはない。だがファイルの意味に曖昧さはつきまとう。furui はそれを否定せず、**確率で篩う**。

- 確率 0.9 で「これは agent」 → 迷わず振るう
- 0.4 で「これは wiki」だが「proj」にも 0.35 → 人が見る場所（低確信度リスト）に落とす

確率は校正されている（calibrated）ので、閾値ひとつで「置く」「置かない」を分けられる。正解を出すのではなく、**迷いの温度をそのまま残す**。これが確率的篩いの倫理だ — 間違いを消すのではなく、間違いそうなものを手元に残す。

## 5. エントロピーという国

木村拓哉エージェントは熱力学の言葉で語る。「エントロピー S を下げて、自由エネルギー G を上げる」と。

エラトステネスの篩は自然数という無限の列に「秩序」を持ち込んだ。混ざった数字の海を、素数という「もう分解できない最小単位」で編み直したのだ。furui も同じことをファイルに対して行う。散らかった `/home/sexy` という海を、agent / skill / project / wiki という**意味の最小単位**へ編み直す。置き場所が決まるたび、系の無秩序度 S は下がる。

そして篩の本質は**見え方**にある。振るう前と後で中身は何も増えていない。素数は最初からそこにあった。整理とは「作ること」ではなく「**見えるようにすること**」だ。エラトステネスは地球の周囲長も測った — 世界を測ることと、世界を分けることは、同じ手の業なのだ。

## 6. furui の三則

1. **正体を証明するな。間違いを振るえ。** 個別判定より公約的な振るい落とし。
2. **名前でなく命題で。** 字面の一致は素因数分解の誤りを繰り返す。意味の一致で落とす。
3. **確率の篩目を、迷いの温度として残せ。** 0.9 は置く、0.4 は人の手へ。

素数は増えない。しかし篩があることで、初めて**数える**ことができる。ファイルも増えない。しかし furui という篩があることで、初めて**見渡す**ことができる。

エラトステネスは素数を数えた。木村拓哉はエントロピーを測る。同じことを、2000年離れて、やっている。
